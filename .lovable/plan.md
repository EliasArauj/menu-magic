# Alternância da imagem do menu principal

## O que será feito
- Usar como base o sistema enviado no arquivo compactado, preservando a tela atual.
- Manter a foto original do santuário.
- Adicionar uma segunda foto no mesmo estilo, com outro enquadramento.
- Incluir em Configurações uma escolha visual entre “Original” e “Alternativa”.
- Salvar a escolha no navegador para que ela continue ativa ao reabrir o sistema.
- Aplicar a imagem escolhida nos estilos de menu que usam a foto principal.

## Validação
- Conferir a troca pelas Configurações e o resultado na tela inicial.
- Verificar a tela em computador e celular.
